# AI 주택 가격 예측 연구소

## 1. 프로젝트 소개

공개된 California Housing 데이터를 활용하여 인공신경망(ANN)으로 캘리포니아 지역의 주택 가격을 예측하는 프로그램입니다.

Python과 Streamlit을 이용하여 데이터 분석, 인공신경망 학습, 예측 결과 시각화, 모델 성능 비교 기능을 구현했습니다.

## 2. 사용 데이터

- 데이터셋: California Housing
- 출처: scikit-learn 공개 데이터셋
- 데이터 수: 20,640개
- 입력 변수: 8개
- 예측 대상: 지역별 주택 가격 중앙값

입력 변수는 중위소득, 주택 연식, 평균 방 개수, 평균 침실 개수, 인구수, 평균 가구원 수, 위도, 경도입니다.

## 3. 인공신경망 알고리즘

- 모델: MLPRegressor
- 입력층: 8개 노드
- 은닉층: 64개, 32개 노드
- 출력층: 1개 노드
- 활성화 함수: ReLU
- 최적화 알고리즘: Adam
- 학습 방법: 역전파를 이용한 가중치 최적화

전체 데이터를 학습용 80%, 테스트용 20%로 분리하고, 입력 데이터를 표준화한 후 인공신경망을 학습시킵니다.

## 4. 주요 기능

1. 공개 데이터 불러오기 및 기초 통계 분석
2. 인공신경망을 이용한 주택 가격 예측
3. 선형회귀 모델과 인공신경망 성능 비교
4. 실제 가격과 예측 가격 시각화
5. 사용자 입력값을 이용한 직접 예측
6. 학습 손실 곡선 시각화
7. 인공신경망 구조별 성능 비교 실험

## 5. 모델 성능

| 평가 지표 | 인공신경망 | 선형회귀 |
|---|---:|---:|
| R² | 0.7905 | 0.5758 |
| RMSE | 0.5239 | 0.7456 |
| MAE | 0.3533 | 0.5332 |

인공신경망이 선형회귀보다 높은 설명력과 낮은 예측 오차를 보였습니다.

## 6. 실행 방법

Python 환경에서 필요한 라이브러리를 설치합니다.

pip install -r requirements.txt

이후 프로그램을 실행합니다.

streamlit run main.py
